# Keyboard shortcuts

Shortcuts work anywhere except while typing in a field. Press `?` in the app to see them.

| Keys | Action |
| --- | --- |
| `.` or `Ctrl`/`⌘` + `K` | Command palette — go to any project page, open a card by key, or search |
| `/` | Search |
| `c` | Create (opens projects) |
| `g` then `h` | Go to the overview |
| `g` then `p` | Go to projects |
| `g` then `s` | Go to search |
| `?` | Show this list |
| `Esc` | Close the palette, a dialog or a popover |

In the palette, `↑`/`↓` move and `Enter` opens. Typing a card key (`JOB-12`) offers to open it
directly; any other text offers a full-text search.
